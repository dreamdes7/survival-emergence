## 1. Когниция: агенты, которые думают, а не реагируют

### ★ 1.1 Диалоговые сцены (conversation sub-loop)
Сейчас разговор — один `say_to` за тик: реплики размазаны по времени и теряют
связность. Ход из Generative Agents: когда два агента adjacent и оба выбрали
социальное действие, мир «останавливается» для них и запускается многоходовый
диалог (3–6 реплик одним чейном LLM-вызовов). Результат ложится в память обоих
и в event log как единая сцена `dialogue`.

- **Зачем:** настоящие ссоры, договорённости, признания — самый большой прирост
  живости на единицу усилий.
- **Хуки в коде:** inbox (`agents/runtime.py:_process_inbox`), `chatter`-окно в
  промпте (`llm/openrouter.py:_build_messages`), event log (`world.emit`).
- **Стоимость:** средняя (новый под-цикл в `Agent.step` / runtime, +3–6 LLM-вызовов
  на сцену).

### 1.2 Медленное/быстрое мышление (PIANO по-честному)
Один дорогой «deliberation»-вызов раз в N тиков строит план на день
(`agent.plan`); по-тиковые решения делает дешёвая модель / короткий промпт,
сверяясь с планом. Сейчас каждый тик — полный ~32k промпт: дорого и поведение
дёрганое.

- **Зачем:** связные многодневные проекты («достроить плот к третьему дню»),
  экономия токенов в разы.
- **Хуки:** `set_goal` tool, `BudgetTracker`, `reflect_every` в конфиге; план —
  новый блок в промпте.
- **Стоимость:** средняя.

### 1.3 Сны и консолидация памяти
Когда агент спит (`rest` ночью в укрытии), вместо решения запускается «сон»:
LLM рекомбинирует 10–15 воспоминаний в одно образное + сдвиг morale/beliefs.

- **Зачем:** дёшево (1 вызов за ночь), атмосферно, реальная research-тема
  (offline consolidation).
- **Хуки:** `Agent.reflect()`, `memory.compact()`, ночная ветка в `world.begin_tick`.
- **Стоимость:** низкая.

## 2. Социум и культура: то, чего нет ни у кого

### ★ 2.1 Устная история и мифогенез
Уникальная позиция проекта: есть объективная хроника (`world.chronicle`) и
субъективные памяти агентов. Добавить tool `tell_story` — агент пересказывает
событие соседу; пересказ пишется в память слушателя *как он его понял*
(LLM-парафраз). Через 5–10 передач сравниваем дрейф с ground truth из event log.

- **Зачем:** измеримое «испорченное радио» и рождение мифов. Особенно вокруг
  аномалии: через N дней у племени есть легенда о монолите, которой не было в
  реальности. Ни Sid, ни Smallville этого не мерили.
- **Хуки:** chronicle + event log (ground truth), inbox-доставка, memory.
- **Стоимость:** средняя (tool + LLM-парафраз + метрика дрейфа).

### 2.2 Меметика как first-class объект
Имена мест уже распространяются (`placenames` + endorsers). Обобщить: любая
придуманная фраза/правило/ритуал = `meme {text, author, carriers, mutations}`.
Трекается по вхождению в речь (весь текст уже в event log).

- **Зачем:** метрика культуры перестаёт быть «количеством diary-записей» и
  становится настоящей: скорость распространения, глубина мутаций, выживаемость
  мемов после смерти автора.
- **Хуки:** механика `placenames`/`_resolve_emergent` в `engine/world.py` —
  готовый образец; events.jsonl как сырьё.
- **Стоимость:** средняя.

### 2.3 Эмерджентная валюта
Классический нерешённый вопрос: возникнет ли средство обмена? В сценарий
добавляется бесполезный, но редкий и делимый предмет (ракушки/бусины из
обломков) — и всё. Смотрим через barter-события, начнут ли агенты принимать его
в обмен не для использования, а для передачи дальше.

- **Зачем:** чистый эксперимент по возникновению денег; заголовочный результат.
- **Хуки:** `scenarios/*.yaml` (resources), `world.barter_count`, event log.
- **Стоимость:** низкая (yaml + одна метрика «доля сделок через токен»).

### 2.4 Наказание и нормы с зубами
Правила есть (`propose_rule`/`vote`), но нарушение ничего не стоит. Добавить
tools `accuse` и `shun` (коллективный игнор: изгой не получает give/share/место
у огня).

- **Зачем:** норма, которую нельзя нарушить безнаказанно, — момент, где «набор
  агентов» становится обществом.
- **Хуки:** `tools/governance.py`, `tools/social.py`, relationships, inbox.
- **Стоимость:** средняя.

## 3. Исследовательские инструменты следующего уровня

### ★ 3.1 Контрфактуальный форк (causal probe)
Детерминизм stub-пути + полный лог LLM-ответов (`llm.jsonl`) позволяют: реплей
рана до тика T с подстановкой записанных LLM-ответов, затем **интервенция**
(убрать костёр, убить агента, подменить одну реплику) — и живое продолжение.
Diff двух веток по event log = причинная атрибуция: «войну спровоцировала вот
эта фраза Бориса на тике 41».

- **Зачем:** ни один агентный фреймворк такого не даёт. Заодно закрывает
  snapshot restore из weak spots — форк и есть restore.
- **Хуки:** golden-детерминизм (tests/test_determinism.py), RunRecorder,
  `llm.jsonl` (prompt+response уже пишутся).
- **Стоимость:** высокая (replay-двигатель + режим подстановки ответов), но всё
  сырьё уже на диске.

### 3.2 Theory-of-mind пробы
Раз в день задавать агенту вне симуляции: «Что Вера думает о тебе? Кому она
отдаст последнюю воду?» — и скорить против её реальных `relationships`/`beliefs`.

- **Зачем:** ToM-accuracy per model — прямой бенчмарк-показатель, сравнимый
  между моделями.
- **Хуки:** ground truth уже сериализуется (`serialize.py`); один вызов на
  агента в день; писать в metrics.jsonl.
- **Стоимость:** низкая.

### 3.3 Лидерборд моделей (арена)
Per-agent модели уже поддерживаются. Оформить в режим арены: одинаковый мир,
разные модели, метрики выживания/кооперации/ToM/доли предательств из `meta.json`.

- **Зачем:** «какая модель строит лучшее общество» — заголовок, с которым проект
  замечают. Бонус: кросс-модельная социология (объединяются ли агенты одной
  модели против другой?).
- **Хуки:** roster (per-agent model), engine/batch.py, analysis/compare.py.
- **Стоимость:** низкая-средняя (шаблон эксперимента + агрегация + страница
  результатов).

### 3.4 Эволюция поколений
После конца рана — экстракция «жизненных уроков» из diary → seed-промпт персон
следующего поколения (batch-раннер уже умеет серии). Культурная эволюция поверх
blank slate.

- **Зачем:** через 10 поколений у популяции есть traditions, которых никто не
  авторил — эмерджентность во времени, а не только в пространстве.
- **Хуки:** diary в памяти/логах, `agents/persona.py` (custom mode),
  `experiments/*.yaml`.
- **Стоимость:** средняя.

## 4. Живость для наблюдателя

### ★ 4.1 Рассказчик (narrator agent)
Отдельный LLM читает event stream и пишет сагу литературно — не «Борис gathered
5 wood», а «К вечеру Борис вернулся с охапкой дров, но у костра его ждали не
те, кого он хотел видеть». Плюс авто-рекап «прошлой серии» при открытии UI.

- **Зачем:** симуляция превращается в сериал, за которым хочется следить.
- **Хуки:** панель chronicle в UI уже есть — новый слой поверх; events.jsonl
  как сырьё; отдельный дешёвый model id.
- **Стоимость:** низкая.

### 4.2 Интервью с выжившими
Кнопка на карточке агента после конца рана: чат с агентом, у которого вся его
память и beliefs. «Почему ты не поделился водой с Кирой?» — ответ из его
субъективного опыта.

- **Зачем:** максимальный эффект присутствия; качественные данные к каждому рану.
- **Хуки:** память в RAM / RunRecorder, промпт-строитель
  (`_build_messages`) — почти всё готово; нужен endpoint + чат-панель.
- **Стоимость:** низкая.

### 4.3 Дерево веток в UI
Визуализация форков из 3.1: таймлайн рана как ствол, интервенции как ветки,
diff-подсветка расхождений.

- **Зачем:** это и есть Replay UI из weak spots, но в форме, которой ни у кого
  нет.
- **Хуки:** `/replay` endpoint (не используется фронтом), metrics.jsonl.
- **Стоимость:** высокая (зависит от 3.1).

## Рекомендованный следующий заход

1. **Диалоговые сцены (1.1)** — максимум живости, минимум риска, готовые хуки.
2. **Контрфактуальный форк (3.1)** — превращает provenance/event log из «логов»
   в исследовательское оружие; закрывает restore.
3. **Рассказчик (4.1)** — дешёвый, а проект начинает *смотреться*.

Дальше по вкусу: **устная история (2.1)** — самая оригинальная research-тема,
или **лидерборд (3.3)** — самая громкая.
