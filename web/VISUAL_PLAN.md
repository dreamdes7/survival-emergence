# Visual & Worldgen Plan — плотный, многослойный, стильный остров

*Диагноз всех «висит в воздухе / утонуло / куб»: декор и посадка считались по
АНАЛИТИЧЕСКОЙ формуле высот, а видимый остров — это сглаженные Chaikin-контуры,
которые возле обрывов расходятся с формулой на 0.5–1 клетку. Лечится не
подгонкой формулы, а сменой принципа.*

## Принцип №1 (архитектурный закон)
**Единственная правда о поверхности — реальный отрендеренный меш** (raycast,
`surfaceY`). Всё, что стоит на земле или крепится к стене, обязано садиться
через одну общую функцию `seatOnMesh()` — никакой параллельной математики.

---

## Фаза 0 — ФУНДАМЕНТ (сейчас)
- [x] `seatOnMesh(x, z, r)`: сэмплирует реальный меш кольцом визуального
      радиуса объекта; если футпринт «сидит верхом» на обрыве — объект
      СОСКАЛЬЗЫВАЕТ от кромки внутрь террасы (до ~1.5 клетки), пока не встанет
      на один уровень; если не нашлось — садится на НИЖНИЙ уровень (в воздухе
      не остаётся никогда). Пруды, структуры — через неё.
- [x] Убрать каменный куб-фундамент (костыль).
- [x] Водопады крепятся к РЕАЛЬНОЙ стене: зонд по мешу шагами 0.1 находит
      фактическую грань обрыва (перепад > 0.6), верх/низ ленты — реальные
      высоты. Нет стены — нет водопада (лента в воздухе запрещена).

## Фаза 1 — ВОДНАЯ СИСТЕМА (главный приём рефа) — ✅ ГОТОВО
- [x] Ручьи: от каждого внутреннего родника steepest-descent по РЕАЛЬНОМУ мешу
      до моря; лента водных квадов на поверхности, UV-скролл = течёт, ширится
      вниз по течению (`buildStreams`). Остров = один водосбор.
- [ ] Шторм-режим (ручьи вздуваются) — позже.

## Фаза 2 — ЯРУСНЫЕ БИОМЫ (высота = характер) — ✅ канопи по высоте
- [x] Верхний пояс (plate ≥ 3): канопи темнее, холоднее и вытянута в шпиль
      (хвойный силуэт); низ — широкие тёплые кроны. Каждый ярус — свой силуэт.
- [ ] Пляжные пальмы с наклоном к морю (позже).

## Фаза 3 — ОДЕЖДА СКАЛ — ✅ осыпи + кекуры
- [x] Осыпи валунов у подножий высоких стен (merged, ~1 дро-колл).
- [x] Морские кекуры (до 4 останцов) в лагуне — силуэт и глубина.
- [ ] Полосы-страты на стенах 2+ ярусов (позже, шейдером стены).

## Фаза 4 — АТМОСФЕРА И ЖИЗНЬ — ✅ в основном есть
- [x] Дымка глубины: scene.fog + прибрежные mist-спрайты (buildFog) — разделяет
      ярусы атмосферной перспективой.
- [x] Птицы дугами (buildSkyLife: чайки кружат), бабочки над лугом, светляки.
- [ ] Стервятники над непогребёнными (Часть III идей — с движком).

## Фаза 5 — СТИЛЕВЫЕ ЗАМКИ — ✅ свет под палитру
- [x] Свет, знающий палитру (WorldPalette.light): Gloaming греет и притемняет
      (золотой час), Boreal — холодно-бледный, Ashfall — свинцовый и тусклый.
      Множители тона/интенсивности поверх суточного света, без аллокаций.
- [x] Цветные тени (тёплое солнце / холодная сине-фиолетовая заливка) — введены.

*Правило готовности каждой фазы: скриншот с 3 ракурсов, где НИЧЕГО не висит,
не тонет и не рождается из воздуха.*
