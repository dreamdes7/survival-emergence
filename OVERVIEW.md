# Survival Emergence — Обзор архитектуры

Мультиагентная симуляция выживания, где LLM-агенты **с чистого листа** (blank slate) должны выработать
социальные структуры, экономику, культуру и нормы. Вдохновлено Emergence World, Altera **Project Sid**
(PIANO), Stanford **Generative Agents**. Цель — исследовать **эмерджентный групповой интеллект**, а не
проигрывать сценарий.

## Стек и раскладка
- **Backend**: Python 3.12, FastAPI + WebSocket. Запуск: `py -3.12 -m api.server`.
- **Frontend**: PixiJS v8 + Vite + TypeScript (`web/`), порт 5173.
- **LLM**: OpenRouter/MegaLLM (по агенту своя модель) или бесплатный эвристический `stub`.

```
engine/    world.py (ядро) · models.py · orchestrator.py · anomaly.py · events.py
           serialize.py · session_log.py · metrics.py · skills.py
agents/    runtime.py (когниция) · memory.py · persona.py · social.py
tools/     core · survival · social · governance · build · settlement · anomaly · culture · bonds · sites
llm/       router.py · openrouter.py · stub.py
api/       server.py (мульти-sim, WS-стриминг, /config/apply, /control)
scenarios/ island.yaml · mars.yaml      config/ world.yaml
web/       src/main.ts (рендер, оверлеи, Forge UI)
```

## Генерация мира (`engine/world.py`)
- **Value-noise** (несколько октав) + **радиальный спад** → маска суши с рваной естественной береговой линией.
  `north_bias` прижимает остров к верхнему краю (земля без воды). Сглаживание убирает острова-крошки.
- **BFS по дистанции до берега** + **высота** + **влажность** (отдельный шум) → биомы:
  пляж/скальный мыс (берег) · луг · **густой лес** (влажные низины) · **скальное нагорье** (пики).
- Ресурсы и структуры размещаются по биому (`grass/jungle/highland/coast/inland`), без наложений,
  с поляной у лагеря. Текущий остров — 60×60.

## Механики мира
- **Физиология** (per-scenario): hunger, thirst, energy, warmth, morale. Падают каждый тик; летальный
  стат при 0 → incapacitated → через 3 тика death. Morale нелетальна.
- **День/ночь**: `day_length_ticks` (12); вторая половина — ночь. Ночью **холодает** (warmth ×1.4; энергию
  ночь не выматывает).
- **«Настоящий холод»**: согреться можно только у **горящего костра**, **горячего источника** или **в укрытии**;
  на открытом ночью тепло утекает. Грейс ~4 ночи, дальше — «обустройся или замёрзни».
- **Ресурсы-ноды**: дерево, фрукты(пальмы), заросли(волокно), камень, **руда(флинт)**, родники, рыбалка.
  Расходуемые ноды исчезают при истощении.
- **Погода**: шторм (усиливает расход тепла/энергии). **Хазард-зоны** (Марс) жгут рядом стоящих.
- **Escape**: чинить сигнальный объект → спасение (опционально по сценарию).
- **Эмерджентный слой** (`_resolve_emergent`): обещания (нарушил → падение доверия), **традиция у костра**
  (≥3 ночью у огня → закрепляется), **топонимы** (имя места расходится по мере прохождения),
  **claims** (метка ноды → конфликт за ресурс).

## Когниция агента (`agents/runtime.py`) — PIANO-петля
Каждый тик: **perceive → process_inbox → retrieve → [reflect] → decide → act → memorize**.
- **Память** (`memory.py`, Generative-Agents): поток записей (observation/action/social/reflection) с
  **importance**; `retrieve` ранжирует по **recency-затуханию + важность + релевантность запросу**.
  `reflect` рекурсивно сворачивает недавнее в строку дневника.
- **Отношения** (`RelationshipBook`): аффинити/ярлык (ally/rival), бонды; рушатся/крепнут от действий.
- **Theory of mind**: `beliefs` — модель других (доверие, заметки, теги), синтезируется из памяти.
- **Скиллы** (`skills.py`): растут от повторения → **эмерджентная специализация** (бонус к добыче и т.п.).
- **Роли** (`role`), **following** (лидерство/следование), **dread** и **gender**.
- **Гейты до LLM**: `_emergency_gate` (критический стат → форс выживания), `_follow_gate` (следование за лидером).
  Решение — JSON-tool-call; `_execute_decision` выполняет через реестр.
- **Blank slate**: никакой авторской личности; имя агент **выбирает сам** (5 предпочтений → жадно без коллизий).

## Инструменты (`tools/`) — ~48–51, контекстная доступность
Каждый тул гейтится по ситуации (рядом нужный объект/состояние), описания на естественном языке —
чтобы модель понимала и использовала гладко.

| Категория | Тулы |
|---|---|
| **core** | go_to · wander · say_to · write_diary · set_goal |
| **survival** | gather · eat · drink · rest · refill_oxygen · build(escape) |
| **social** | give · share_location · follow · warn · claim · gossip · promise |
| **governance** | propose_rule · vote · assign_role · expel_member · announce |
| **build** | build_structure · maintain · stash · grab(склад) |
| **settlement** | craft(топор/копьё/сеть) · cook(сушка) · plant · harvest_crop · post · read_sign · scan · repair |
| **anomaly** | investigate_anomaly · offer · press_button |
| **culture** | name_place |
| **bonds** | propose_friendship · confess_feelings · accept_bond · reject_bond · declare_enemy |
| **sites** (Марс) | investigate · examine · breach |

Инструменты-множители: **axe** ×2 дерева, **net** ×2 рыбы, **dried_food** ×1.6 сытости.

## Структуры
- **Строящиеся** (`build_structure`, оплата материалами + прогресс по тикам): campfire, tent(вместимость 2),
  water_still, store, **workbench**, **smokehouse**, **garden**, **well**, **signpost**, **watchtower**.
- **Природные** (на генерации): **горячий источник** (тепло), **пещера** (укрытие на 3), руда.
- **Ориентиры** (чинятся `repair`): **маяк** (загорается → ночная мораль-надежда, glow), **радиовышка** (сигнал).
- Все футпринты **квадратные** (текстуры не тянутся), рендер с привязкой к низу.

## Подсистема аномалий (`engine/anomaly.py`, `tools/anomaly.py`)
Опциональный режим (Forge → `anomaly`, по умолчанию одна). **Лор — скрытый ключ для нас**, агентам идут
только **двусмысленные перцепты**; смысл (религия/ритуал/табу/раскол) — эмерджентный выход, не сценарий.
- **`dread`**: растёт у объекта, спадает вдали; на пике — **впрыск ненадёжного восприятия**
  (мнимые движения/голоса) + просадка морали.
- **Манифестация**: редкое событие на весь остров с **грубым направлением** = механика обнаружения + общий перцепт.
- **Люк (эталон)**: обратный отсчёт + кнопка `press_button`; пропуск → **двусмысленное последствие**
  (50% дурное знамение / 50% ничего) → ритуал на прерывистом подкреплении.
- Виды: hatch · monolith · idol · whisperzone · relic (полный ритуал пока у hatch; остальные — dread+манифест+offer).

## LLM-слой (`llm/`)
- **router**: маршрутизирует вызовы по `agent.model`; поддерживает смешанные модели на агентов.
- **openrouter**: HTTP к OpenRouter/MegaLLM; парс контента (фолбэк на `reasoning`), бюджет токенов/USD,
  устойчивость к `content=null`. Системный промпт — человек по-русски, без координат/робо-речи, с подсказками
  по выживанию/стройке. `propose_names` для самоназвания.
- **stub**: бесплатная эвристика (реактивное выживание + базовый соц-обмен) — тест механик без токенов.

## API и стриминг (`api/server.py`)
- **Мульти-sim**: несколько миров параллельно (`runners`, sim-id).
- `GET /state`, `/replay`, `/config`; `POST /sims/{id}/config/apply` (сценарий, агенты, seed, провайдер,
  модели, per-agent, **anomaly**, бюджеты), `POST /control` (pause/resume — стоп токенам).
- **WS `/ws`**: пуш снапшота каждый тик. LLM-вызовы — `asyncio.to_thread` (event loop не блокируется).

## Логирование (`engine/session_log.py`)
JSONL на каждый применённый мир в `logs/session_<scenario>_<ts>.jsonl`: шапка (агенты/модели/seed),
**каждый тик** (действия/мысли/реплики, смерти+причины, новые постройки), **дневной срез статов**,
итоговая сводка. Читается офлайн для разбора эмерджентности.

## Frontend (`web/src/main.ts`)
- Слои: запечённый terrain (без швов на зуме) → объекты (z-сорт по Y) → облака → ночной оверлей.
- Анимации: пешки (бег/флип), пена берега, качающиеся кусты, дрейф облаков, **glow** огня/маяка,
  плавная **ночь** (синее затемнение + шторм).
- **HTML-оверлей**: имена и баблы речи (чёткие, зум-независимые).
- **Forge** (левая панель): сценарий/seed/дни/агенты/провайдер/модели per-agent/**anomaly**/бюджеты → Apply.
  Activity log, пауза, выбор агента, карточка с физиологией/отношениями/целями.

## Метрики (`engine/metrics.py`)
AWI-показатели (бартер, кооперация, конфликты, культурные события и т.п.) — в снапшоте для наблюдателя.
